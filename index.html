Projeto de Desenvolvimento de Jogos Web com IA


  • Objetivo: Este projeto teve como objetivo explorar o desenvolvimento de jogos web simples utilizando Inteligência Artificial (IA).


  • Automatização: A maior parte dos jogos foi desenvolvida com pelo menos 80% de sua produção automatizada por ferramentas de IA.


  • Tecnologias: As principais tecnologias utilizadas incluem o ChatGPT-4 para geração de conteúdo, o Photoshop AI para criação de gráficos, e o Ideogram.ai para design visual.


  • Desenvolvimento de Jogos: Todos os jogos foram desenvolvidos utilizando a biblioteca Phaser, uma poderosa ferramenta para desenvolvimento de jogos 2D baseados em HTML5.


  • Ranking: O sistema de ranking dos jogadores foi implementado utilizando Node.js para o backend, garantindo uma experiência fluida e em tempo real.


  • Conclusão: Este projeto destaca o potencial das soluções de IA no processo criativo e técnico, facilitando o desenvolvimento de jogos com qualidade e eficiência.



  • O projeto é open source e o código pode ser encontrado em: https://github.com/BrunoFMPassos/game-ai
